Three words, never a number

Proximity is a hop count over named anchors, reduced to nearest, same zone or far. The hop count is computed and never shown.

No trail

A check-in replaces the last one, so there is no location history — and no member's exact coordinates exist anywhere in the room.

Get it

Offline. A LAN transport does exist in this estate — `lan-kit`, zero dependencies, SSE and POST — but it is not wired into this app. What ships here is a same-device bus, so the room logic runs and can be tested.
