Nearby

Find the people you came with, inside a venue. Coarse proximity, no GPS, no coordinates.

about

The transport is not built. This demo runs the whole room on one device: the same engine, the same tiers, the same pins — but the LAN link between phones is named as absent rather than faked. Proximity here is real logic over anchor check-ins.

The room

    Where you are

    Check in at an anchor. A check-in replaces the last one — there is no trail to leak.

    How near

    Three words, never a number: the hop count is what the app computes and the tier is what you are shown.
